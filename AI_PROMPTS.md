# Sanitized AI prompt index

The project author used OpenAI Codex as an engineering assistant. The prompts
below summarize the work requests without reproducing credentials or private
approval material.

1. Inspect the repository, run the existing tests, and map the architecture.
2. Crawl the official ETHOnline 2026 prize and judging pages; identify exact
   qualification gates for the selected ENS, Chainlink, and Privy tracks.
3. Read the hackathon win-playbook guidance and turn it into an evidence-first
   submission checklist.
4. Stress-test the policy gate, API validation, revocation, proof persistence,
   and signer boundaries; report bypasses with reproducible cases.
5. Implement only reviewed, surgical hardening changes and add regression tests.
6. Reconcile every sponsor claim with a current official SDK call site and an
   executed artifact before marking it live.

No prompt in this public index contains a private key, app secret, wallet seed,
authorization signature, or other sensitive payload.
