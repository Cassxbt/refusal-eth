# AI-use disclosure

This project used OpenAI Codex during ETHOnline development for repository
inspection, test-harness work, security review, sponsor-document research, and
implementation assistance. Human review and execution decisions remain the
responsibility of the project author.

The build specification, verification commands, and submission task list are
included in this repository so the work can be audited from a clean clone.
No private keys, app secrets, approval payloads, or other credentials belong in
the repository or in the public evidence.
